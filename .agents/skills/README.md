# Скиллы Codex для WorkTimeRegister

Каждый скилл работает сам по себе: вызвал один, Codex применил только его. Вызов: `$имя` в начале запроса или выбор из `/skills`. Без вызова Codex работает как обычно.

### `$cs-review`: проверить правку

`$cs-review проверь мой незакоммиченный дифф`

Codex сверит дифф с чеклистом проекта и выдаст отчёт с номерами нарушений. Код не трогает. Исправит только то, что назовёшь: «исправь 2 и 4».

### `$cs-tests`: написать или починить тест

`$cs-tests напиши тест: пауза через полночь не считается работой`

Тест по образцу существующих: настоящая SQLite во временной папке, время подменяется в тесте, без ожиданий по часам.

### `$investigate`: разобраться, почему цифры не те

`$investigate за 28.10 работа на час больше, чем должна быть`

Причина со ссылками на код и строки копии базы, тест, который повторяет ошибку, и предложенный фикс. Код не меняет.

### `$sqlite`: что-то с базой

`$sqlite где хранить комментарий к перерыву`

Предложит колонку или таблицу, миграцию с резервной копией базы и тест миграции. В базу пользователя не пишет.

### `$cs-guide`: правка кода по правилам проекта

`$cs-guide добавь настройку длины перерыва`

Сначала план: в какой слой класть код, как считать время. Правка после твоего «да».

---

Устанавливать ничего не нужно: Codex сам находит `.agents/skills/`. Если скилла нет в `/skills`, перезапусти Codex. Если скилл расходится с `AGENTS.md`, выполняется правило `AGENTS.md`.
