# Скиллы Codex для WorkTimeRegister

Скилл работает только по вызову: `$имя` в начале запроса или выбор из `/skills`.

| Скилл | Состояние |
| --- | --- |
| `$cs-review` | Готов. Ревью правки по лучшим практикам C# (.NET 10, C# 14), Avalonia, SQLite и тестов и по правилам `AGENTS.md` |
| `$cs-guide`, `$cs-tests`, `$sqlite`, `$investigate` | Лежат в репозитории, но под проект ещё не адаптированы. Пока не использовать |

## `$cs-review`

- `$cs-review` проверяет незакоммиченную правку, `$cs-review ветка против main` проверяет ветку, `$cs-review коммит abc1234` проверяет один коммит.
- Результат: таблица нарушений с номерами, изменения поведения на подтверждение, итог PASS или CHANGES REQUIRED.
- Код не трогает. Исправит только то, что назовёшь: «исправь 2 и 4».
